# ScienceoLogy

**ScienceoLogy** is designed for Class 5 to 10 students preparing under CBSE, ICSE, and WBBSE (Madhyamik) curricula.
<br>
Mentored by Md Amaan [B.Sc. (Hons.) Mathematics, CU]
<br>
The platform provides single-click access to curated formula sheets, daily quizzes, past examination papers, and timed mock tests without mandatory sign-ups or paywalls.
