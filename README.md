# ScienceoLogy

> Free, open-access Mathematics & Science resources for Classes 5–10 (CBSE, ICSE, WBBSE).

ScienceoLogy provides school students with direct, friction-free access to core learning materials without paywalls or mandatory sign-ups.

### 📚 Core Features
* **Study Notes & Formulas:** Downloadable revision sheets and verified proofs.
* **Video Lessons:** Conceptual walkthroughs linked directly to YouTube.
* **Daily Flash Quiz:** Instant single-question concept checks.
* **Timed Test Series:** Topicwise (15m), Chapterwise (15m), and Full Mocks (40m) with randomized, unlimited reattempts.
* **Board PYQs:** Solved past exam papers.
